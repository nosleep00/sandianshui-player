# 三点水播放器（SandianshuiPlayer）

一个安卓本地音频播放器，同时支持用户**自备接口**的在线音源搜索与流式播放，以及**自备 API Key** 的 AI 语音识别与翻译。

技术栈：**Kotlin + Jetpack Compose + Media3（ExoPlayer）+ SAF + Coil + 极简 MVVM**。

- 不内置任何在线音源接口地址，也不包含任何 API Key。
- 接口地址与所有密钥均由用户在应用内填写，仅保存在本机（Android 私有存储），不会随应用分发或上传。

## 功能特性

### 本地播放

- 本地音频 **mp3 / wav** 导入与播放：支持「选择所在文件夹」整文件夹导入，或「导入单个音频文件」；不申请存储权限。
- 同名自动匹配 **SRT / VTT / LRC**：按 `.srt → .vtt → .lrc` 优先级，字幕优先于歌词。
  - 支持变体后缀命名，如 `歌.zh.srt`、`歌.zh-CN.srt`、`歌.16k.srt`；精确同名 > 中文变体 > 其他变体。
  - 兼容「另存为 .txt」：`xxx.srt.txt`、`xxx.lrc.txt` 仍能识别；纯说明性 txt 不会被当成字幕。
- 音频 / 字幕分文件夹也能自动匹配：按文件夹名与内容自动识别，跨文件夹按同名一一配对。
- 字幕 / 歌词时间轴：大卡片在「封面 / 时间轴」间切换，当前句高亮并自动滚动，点击任意一句即跳转播放。
- 单句不限长度，自动换行完整显示，不截断、不省略。
- 可拖动的悬浮字幕框：实时显示当前句，长句完整换行，句间保留上一句，可拖到屏幕任意位置。
- 桌面悬浮歌词：切到其他 App / 回桌面仍显示在最上层并实时更新，由前台服务保活，后台继续播放。
- 多编码自动识别 + 手动切换：支持 **UTF-8、UTF-16LE、Shift_JIS、GBK**，按 BOM / 字节结构自动识别；右下角「编码」按钮可手动切换，本地与在线通用。
- 深度检索字幕 / 歌词：递归遍历整个已授权文件夹（本地）或整棵作品文件树（在线），按严格同名优先、模糊包含兜底匹配。
- 封面：自动匹配同名图片，也可手动导入；切歌后手动封面保留，导入新图片才覆盖。
- 倍速：0.5x – 5.0x 连续可调，拖动即生效。
- 可拖动进度条、播放 / 暂停、当前时间 / 总时长、上一首 / 下一首切换。

### 在线音源（需自行配置接口）

- 顶部「在线」页签提供关键词搜索，默认按销售数量降序、每页 20 条，支持上一页 / 下一页翻页。
- 点击作品先展开其全部音轨，再点具体音轨才在线流式播放，不下载到本地。
- 若音轨带同名 LRC / SRT / VTT，播放时实时拉取并显示，倍速下按真实位置同步、不漂移。
- **应用不内置接口地址**：首次使用前，点搜索框旁的齿轮图标，在「音源接口设置」中填写与所用 JSON API 兼容的接口根地址。应用会在其下拼接 `/api/search/<关键词>`、`/api/tracks/<作品ID>` 等路径。地址仅保存在本机，留空保存即清除。
- 未配置接口地址时点击搜索，会自动弹出接口设置对话框。

### AI 语音识别与翻译（需自行填写 API Key）

- 在线播放时点右下角「AI译」→「开始翻译」，先做语音识别，再批量翻译为中文，生成带时间轴的 **SRT 字幕**，在悬浮框 / 时间轴 / 桌面悬浮窗中与音频同步显示。
- 语音识别（ASR）可选：
  - 阿里百炼 **paraformer-v2**（异步）
  - **ElevenLabs Scribe（scribe_v1）**（词级时间戳）
  - **AssemblyAI**（异步提交 + 轮询，词级时间戳，毫秒单位）
- 文字翻译可选：
  - **DeepSeek Flash**（OpenAI 兼容）
  - **Google Gemini**
  - **Lara Translate（Translated）**：Access Key ID + Secret 双凭据，HMAC 换 JWT
  - **Groq（openai/gpt-oss-20b）**：OpenAI 兼容，支持五档上下文能力
- 翻译完成后可「保存到本地」（系统文件选择器自行选择位置）或「仅本次使用」（不保存、退出自动清理）。结果按音频 URL 缓存，同一音频再次翻译秒回。
- 多服务商可切换、配置历史保留：每个服务商的 Key 独立保存，切换不丢失。Lara 需填 Access Key ID 与 Secret 两个值。
- **Groq 上下文能力五档调节**：选中 Groq 后可用滑块在「弱 / 较弱 / 中 / 较强 / 强」间切换。档位越高，参考前后文越多（0～4 句）、推理深度越高，译文更自然但耗时越长（约为弱档的 1.0～2.9 倍）。配置界面显示推理强度、上下文句数与每 10 句预估耗时，翻译遮罩按总句数显示「预估还需约 X 分 Y 秒」。档位随配置持久化，默认「中」。

## 隐私与安全

- 应用**不收集、不上传任何数据**，仅申请网络访问权限用于在线音源与 AI 服务。
- 在线音源接口地址、各服务商 API Key（含第二凭据）、Groq 档位均保存在应用私有目录（SharedPreferences），其他应用无法读取，卸载即清除。
- 源码中不包含任何真实凭据；请使用你自己申请的合法 API Key，并遵守对应服务商的条款。

## 在 Android Studio 中运行

1. 用 Android Studio 选择 `Open` 打开本目录，等待 Gradle Sync 完成（需联网下载依赖）。
2. 启动一台 Android 模拟器（建议 API 26 及以上），或连接开启 USB 调试的安卓手机。
3. 点 **Run ▶** 即可安装运行。

> 首次构建若提示找不到 Android SDK，IDE 会自动生成 `local.properties`（已在 `.gitignore` 中，不会提交）。

## 命令行构建

```bash
# 构建 Debug APK
./gradlew :app:assembleDebug

# 运行单元测试
./gradlew :app:testDebugUnitTest
```

Windows 下使用 `gradlew.bat`，并确保已设置 `JAVA_HOME` 与 `ANDROID_HOME`。

## 工程结构

```
app/src/main/java/com/sandianshui/player/
├── MainActivity.kt
├── core/
│   ├── player/      # PlayerEngine 接口 + Media3 实现
│   ├── subtitle/    # Cue 模型、SRT/VTT/LRC 解析、同名匹配、编码识别与解码
│   ├── media/       # MediaTrack、Playlist、SAF 文件夹扫描、文本读取
│   ├── overlay/     # 跨 App 系统悬浮窗
│   ├── remote/      # 轻量 HTTP、在线音源接口解析、接口地址存储
│   ├── translate/   # ASR / 翻译 Provider、SRT 组装、管线编排、缓存、密钥存储
│   └── ext/         # 在线扩展预留接口
├── ui/
│   ├── theme/       # 固定暗色主题
│   └── player/      # 界面、ViewModel、状态、悬浮框与在线搜索面板
└── util/
app/src/test/        # 单元测试
```
